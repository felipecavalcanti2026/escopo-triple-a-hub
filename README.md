# Triple A Hub — Escopo de construção

Documento de trabalho da sociedade (Bruno Guerra · Kauan · Felipe Cavalcanti).

Define o reposicionamento do Triple A Hub de hub de crescimento para **casa de produtos
digitais**: as quatro frentes (lançamentos, perpétuo com VSL, eventos e webinários,
mentorias), o dono de cada uma, a sequência em quatro ondas de 90 dias, o Projeto
Autoridade para Kauan e Felipe, a estrutura societária e as decisões pendentes.
