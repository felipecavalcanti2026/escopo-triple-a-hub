# Triple A Hub — Escopo de construção

Documento de trabalho da sociedade (Bruno Guerra · Kauan · Felipe Cavalcanti).

O Hub continua sendo hub — o que muda é o mercado. Define as quatro frentes que o Triple A
Hub passa a operar no mercado de infoprodutos (lançamentos, perpétuo com VSL, eventos e
webinários, mentorias), o dono de cada uma, a sequência em quatro ondas de 90 dias, o
Método Triple A aplicado à própria empresa, o Projeto Autoridade para Kauan e Felipe, a
estrutura societária e as decisões pendentes.
